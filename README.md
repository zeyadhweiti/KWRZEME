# 🖼️ معرض الصور الكروي 3D

موقع تفاعلي لعرض الصور على سطح كرة ثلاثية الأبعاد باستخدام Three.js.

## ✨ المميزات

- 🌍 **عرض كروي ثلاثي الأبعاد** - الصور موزعة على سطح كرة
- 📤 **رفع الصور** - اختر ملفات من جهازك
- 🖱️ **تفاعل كامل** - سحب للدوران، تكبير بالعجلة، نقر لعرض الصورة
- ⚙️ **تحكم بالحجم** - تعديل نصف قطر الكرة ودقة التقسيم
- 🔄 **دوران تلقائي** - تشغيل/إيقاف الدوران
- 📱 **تصميم متجاوب** - يعمل على جميع الأحجام

## 🧮 المعادلة الرياضية

```
x = R × sin(φ) × cos(θ)
y = R × cos(φ)
z = R × sin(φ) × sin(θ)

حيث:
  φ ∈ [0, π]   (الزاوية الرأسية)
  θ ∈ [0, 2π]  (الزاوية الأفقية)
  R = نصف القطر
```

## 🚀 التشغيل

افتح ملف `index.html` مباشرة في المتصفح. لا يحتاج خادم (Server) لأن Three.js يُحمل من CDN.

## 🌐 النشر على GitHub Pages

1. ارفع الملفات على مستودع GitHub
2. اذهب إلى **Settings → Pages**
3. اختر **Deploy from a branch**
4. اختر الفرع `main` والمجلد `/ (root)`
5. اضغط **Save**
6. انتظر دقيقة ثم افتح الرابط المُنشأ
